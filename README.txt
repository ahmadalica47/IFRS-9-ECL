IFRS 9 ECL Calculator - source code

This ZIP contains the source from the current published version of Ali's IFRS 9 ECL Calculator File, including its source files and image asset.

The app uses Instinct's @instinct/files components and runtime (including FileRouter and UI components). It runs within the Instinct File environment and will not build or run independently on another host as-is. Hosting it elsewhere would require replacing those Instinct components and adding the host's own project/build setup.

The project configuration lists the World Bank API as an allowed origin for macroeconomic data. No customer receivables or other user-uploaded data are included in this source ZIP.
